# M2 — Quản trị dự án: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admin tạo dự án gắn với repo GitHub (chọn bằng dropdown) và một file Google Sheet riêng. Admin/QA Lead quản lý thành viên, màn hình (kèm `code_paths`) và giao màn hình cho tester có deadline. Tester xem việc của mình ở trang "Việc của tôi".

**Architecture:** Xây trên M1, không đổi kiến trúc. Dữ liệu dự án nằm ở tab `Projects`/`ProjectMembers` của Sheet hệ thống. Màn hình và việc được giao nằm trong Sheet riêng của từng dự án. GitHub được gọi qua một `GitHubClient` (Protocol) giống cách M1 bọc Google Sheets, để test thay bằng bản giả. Router chỉ kiểm tra quyền rồi gọi service; service gọi repository.

**Tech Stack:** Như M1. Backend thêm `pyjwt[crypto]` (ký JWT cho GitHub App) và dùng `httpx` (đã có) để gọi GitHub REST API. Frontend không thêm thư viện.

**Spec:** `docs/superpowers/specs/2026-11-12-ai-test-runner-design.md` (mục 4, 7.3, 7.4, 7.5, 8, 9, 10.2, 11)

## Global Constraints

- Tiếp tục làm trên nhánh `feature/m1-foundation` (chủ dự án yêu cầu). Không merge, không push, không tạo PR.
- Commit theo Conventional Commits, mô tả bằng tiếng Việt có dấu (`feat(api): thêm API dự án`). Viết message bằng heredoc trong Git Bash.
- Toàn bộ quy tắc của M1 vẫn giữ: chỉ `backend/app/core/sheets/gateway.py` được import `googleapiclient`; chỉ `backend/app/core/github/client.py` được gọi GitHub; ánh xạ Sheet theo tên cột; mọi chuỗi giao diện nằm trong `frontend/messages/vi.json`; lỗi API trả `{"detail": "<câu tiếng Việt>"}`; `mypy --strict`, `ruff`, TypeScript strict đều sạch.
- Mỗi lần ghi đều ghi AuditLog: thay đổi dự án/thành viên ghi vào AuditLog của Sheet hệ thống; thay đổi màn hình/việc được giao ghi vào AuditLog của Sheet dự án.
- Khoá theo spec mục 9: sinh ID dùng `lock:id:<project_id>:<entity>`; ghi một tab dùng một khoá cho cả tab (bài học từ review M1): `lock:system:projects`, `lock:system:project-members`, `lock:<project_id>:screens`, `lock:<project_id>:assignments`.
- Người không phải thành viên (trừ Admin) gọi API của dự án nhận **404 "Không tìm thấy dự án"**, không phải 403, để không lộ dự án tồn tại.
- Dự án đã lưu trữ: chỉ Admin còn thấy. Mọi thao tác ghi vào dự án lưu trữ (trừ bỏ lưu trữ) trả **409 "Dự án đã được lưu trữ"**.
- Next.js 16 có thay đổi lớn: **trước khi viết route động `[projectId]`, đọc `frontend/node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/dynamic-routes.md`** và phần "Working with runtime APIs" trong `01-getting-started/08-caching.md` (đang bật `cacheComponents`).
- Ghi giả định mới vào cuối `DECISIONS.md`.

## Review Focus

1. **Người ngoài đoán URL dự án** (`/api/projects/PRJ-0002/...`): nhận 404 ở mọi endpoint con, kể cả khi dự án tồn tại. Test ở Task 4.
2. **Spreadsheet nhập vào là link đầy đủ** (`https://docs.google.com/spreadsheets/d/<ID>/edit#gid=0`, có khoảng trắng), hoặc trùng Sheet hệ thống, hoặc trùng Sheet của dự án khác: link được tách lấy ID; hai trường hợp trùng trả 409. Test ở Task 2 và Task 4.
3. **Hai người tạo màn hình cùng lúc**: không bao giờ trùng mã `SC-0001`. Test bằng 2 thread ở Task 1.
4. **Giao việc cho người không hợp lệ** (không phải thành viên, không phải Tester, đã bị khoá) hoặc **deadline trong quá khứ**: trả 422 kèm câu báo rõ. Test ở Task 6.
5. **Bỏ thành viên đang được giao việc**: trả 409 "Người này đang được giao N màn hình", không để lại việc mồ côi. Test ở Task 7.

**Interfaces:**
- Produces:
  ```python
  class RepoInfo(BaseModel): full_name: str; default_branch: str; private: bool
  class GitHubNotConfiguredError(Exception): ...
  class GitHubError(Exception): ...   # message tiếng Việt

  class GitHubClient(Protocol):
      def list_repositories(self) -> list[RepoInfo]: ...
      def list_branches(self, repo_full_name: str) -> list[str]: ...

  class GitHubAppClient:
      def __init__(self, app_id: str, private_key: str, *, http: httpx.Client | None = None,
                   now: Callable[[], float] = time.time) -> None: ...
  def normalize_private_key(value: str) -> str   # đổi chuỗi "\\n" thành xuống dòng thật
  ```
- Luồng: ký JWT RS256 (`iat = now - 60`, `exp = now + 540`, `iss = app_id`) → `GET /app/installations` → với mỗi installation `POST /app/installations/{id}/access_tokens` (giữ token trong bộ nhớ tới `expires_at - 60s`) → `GET /installation/repositories?per_page=100` (đi theo header `Link: rel="next"`). `list_branches`: `GET /repos/{owner}/{repo}/installation` bằng JWT để biết installation, rồi `GET /repos/{full_name}/branches?per_page=100` bằng token của installation đó. Kết quả sắp xếp theo tên.
- Header: `Accept: application/vnd.github+json`, `X-GitHub-Api-Version: 2022-11-28`. Base URL `https://api.github.com`.
- `FakeGitHub(repos: dict[str, list[str]])` trong `fakes.py`: key là `full_name`, value là danh sách branch.
